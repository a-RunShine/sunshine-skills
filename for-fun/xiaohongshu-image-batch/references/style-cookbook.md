# 风格词典（Style Cookbook）

4 套经典风格 + 自定义规范 + 代码块通用规范。

---

## 风格 A：暖色手绘 ⭐ 最常用

**典型使用场景**：算法题解、生活随笔、读书笔记、知识科普。

| 元素 | 规格 |
|------|------|
| 画布底色 | `#F8F4ED` 米色 |
| 主描边色 | `#8AAEC9` 淡蓝（线条略不规则，手抖感） |
| 主高亮色 | `#F4C580` 奶油黄 |
| 辅助色 | `#A6E3A1` 淡绿（成功/最优）；`#E07A7A` 粉红（错误/次优） |
| 标题字体 | 圆润中文（站酷快乐体、演示佛系体类） |
| 装饰风格 | 手绘描边、不规则圆角、emoji 用手绘圈圈框起来 |
| 反差点缀 | 暖色画布 + 黑底代码框（视觉混搭） |

**Prompt 必带开头**：
```
米色画布背景（#F8F4ED），所有元素手绘铅笔描边风
（描边 #8AAEC9 淡蓝、线条略不规则）。
标题用圆润中文（站酷快乐体/演示佛系体类）。
```

## 自定义风格

**只填 3 个色 + 1 个字体感觉即可**：
1. 画布底色（hex）
2. 主描边色（hex）
3. 主高亮色（hex）
4. 字体感觉（圆润/手写/粗体/宋体）

辅助色可省略。

## 代码块规范（无论哪种风格都用这个）

代码块在暖色画布里是"黑底 macOS 风格"，是合规的视觉混搭。

| 元素 | 规格 |
|------|------|
| 背景 | `#1E1E1E` 黑 |
| macOS 圆点 | `#FF5F57` 红 / `#FEBC2E` 黄 / `#28C840` 绿 |
| 字体 | monospace（等宽） |

### VS Code 默认配色（推荐）

| 元素 | 颜色 | 例 |
|------|------|-----|
| 关键字 | `#569CD6` 蓝 | public, boolean, while, if, return, null, new |
| 类名 | `#DCDCAA` 黄 | ListNode, Solution |
| 变量名 | `#D4D4D4` 浅灰白 | head, slow, fast, val, next |
| 字符串 | `#CE9178` 橙 | "hello" |
| 运算符 | `#FFFFFF` 白 | =, !=, &&, == |
| 括号 | `#DCDCAA` 黄 | (, ), {, } |
| 注释 | `#6A9955` 绿 | //, /* */ |

### 紫色调配色

| 元素 | 颜色 |
|------|------|
| 关键字 | `#C586C0` 紫 |
| 类名 | `#4EC9B0` 青绿 |
| 变量 | `#FFFFFF` 白 |
| 括号 | `#DCDCAA` 黄 |

### 简化版（无高亮）

黑背景 + 纯白代码 + 黄色高亮关键字。最简单但最弱。

## 关键经验

⚠️ **Gemini 渲染代码经常乱码**：
- 不知道 Java 关键字怎么拼（如 `Lavetope`、`Reilnewrten`）
- **修复**：在 prompt 里给完整代码 + 强调"按字生成、不能多字少字、不能拼错英文单词"

⚠️ **代码框是黑底，不管外层什么风格**：
- 暖色手绘 + 黑底代码块 = 合规混搭
- 极客深色 + 黑底代码块 = 整体统一
- 不需要在任何风格下把代码块也染成暖色

⚠️ **风格定调要靠一张锚图对齐**：
- 第一次出的图作为"风格样本"
- 用户认可后，提取 5 项规范写入后续所有 prompt
- 避免每张图单独 prompt 导致风格跑偏
