# Project Brief 模板

grill 完之后的**唯一**项目综合概览。**执行层（出图）直接照这个走**。

---

## 模板

```markdown
# Project Brief：<主题>

> 由 /grilling 对齐生成的项目上下文。供 agent 后续出图参考 + 用户阅读确认。
>
> **用法**：
> 1. Grill 完之后复制本模板
> 2. 把 `<>` 占位符替换为实际决策
> 3. 给用户看一遍确认 → 出图时严格按 brief 执行

## 配套规范

### 标题模板

```
<如：带你刷力扣 #XX｜我写了 50 行，大佬只要 5 行｜回文链表>
```

### 正文结构

- **开头钩子**（3-5 行）：<如：自嘲/震惊/共鸣>
- **核心内容**（5-10 行）：<如：对比 / 数字 / 套路>
- **收尾金句**（1-2 行）：<如：万能模板 / 收藏钩子>

### Tag 模板

```
#<系列号> #<主题> #<类别1> #<类别2> ...
```

### 评论区置顶

```
<如：代码太长放不下了，整理成完整笔记了，要的扣 1，下期更新 XX>
