# 错误处理手册（Error Playbook）

5 类常见 bug + 修复方法。每张图出图后**必查**。

---

## Bug 1：代码乱码 ⭐⭐⭐ 最常见

**症状**：
- Java 关键字拼错（如 `Lavetope`、`Reilnewrten`、`Rarout`、`nanos`）
- 变量名是乱字符
- 整段代码读不懂

**原因**：
Gemini 不知道 Java 关键字怎么拼（它见过 Java 代码但没"记住"）。

**修复**：
1. **重做时在 prompt 里给完整代码 + 强调"逐字生成"**
2. 完整 prompt 必带：
   ```
   代码用 monospace 等宽字体，按以下内容逐字生成
   （不能多字少字、不能拼错英文单词）：
   [完整 Java 代码]
   ```
3. 关键代码补一行：「关键字 public boolean while if return null new 用蓝色，类名 ListNode 用黄色」

**接受度**：
- 如果还是错——**可以接受**：乱码本身强化"我凌晨 3 点的解法 😅"自嘲人设
- 但**封面、关键页**（方法 3 巧办法）必须重做到对

---

## Bug 2：风格割裂 ⭐⭐

**症状**：
- 几张图风格不统一（颜色深浅不一致、字体感觉不同）
- 装饰元素有的有、有的没有
- 暖色画布里有图冷色画布

**原因**：
每张图单独 prompt，模型自由发挥不一致。

**修复**：
1. **重做时锚图风格规范必须显式写进每个 prompt**
2. 每个 prompt 开头都写：
   ```
   [风格规范]
   米色画布背景（#F8F4ED）
   所有元素手绘铅笔描边风（描边 #8AAEC9 淡蓝、线条略不规则）
   标题用圆润中文（站酷快乐体/演示佛系体类）
   ```
3. 参考 `style-cookbook.md` 的 prompt 开头模板

**预防**：
- 风格定调**必须用一张锚图**作为基线
- 不要每张图风格独立发挥

---

## Bug 3：封面与内容页割裂 ⭐

**症状**：
- 封面极客深色、内容页暖色手绘，反差过大
- 用户从封面进入内容页"跳戏"

**原因**：
封面是单独决策点，没参考内容页风格。

**修复**：
1. 封面定调时**参考已确认的锚图色板**
2. 风格可以略夸张（封面要抓人），但**底色和字体感觉必须统一**
3. 如果锚图是暖色手绘，封面也用暖色画布 + 手绘描边，**只在内容上夸张**（如"我 50 行 vs 大佬 5 行"对比）

**替代方案**：
- 纯黑/纯白封面 + 暖色内容页 = 跳戏，避免
- 暖色封面 + 暖色内容页 = 统一但首图可能不够抓眼
- **暖色封面 + 暖色内容页 + 封面有"硬反差"**（如左右代码框对比）= 最佳

---

## Bug 4：文字溢出 / 字号过小 ⭐

**症状**：
- 标题太大被裁切
- 说明文字太小看不清
- 中英文混排时溢出

**修复**：
1. prompt 里**明确字号相对关系**（"超大" vs "中" vs "小"）
2. 重点内容用「必须清晰可读」约束
3. 避免在一张图里塞太多文字（超过 30 个中文字 = 风险）

**预防**：
- 标题 ≤ 15 个字
- 副标 ≤ 20 个字
- 说明文字 ≥ 18pt（视觉上）

---

## Bug 5：装饰元素过载 ⭐

**症状**：
- emoji + 边框 + 箭头 + 框中框，视觉太乱
- 配色过多（5 种以上颜色）
- 文字 + 图标 + 装饰元素都在抢注意力

**修复**：
1. 限制每张图装饰元素 ≤ 3 类
2. emoji 用在"对话/情感"位置，不滥用
3. 主色 + 辅助色 = 2-3 种足够

**预防**：
- 风格定调时定好"装饰上限"
- 暖色手绘：emoji + 描边 + 圆角 = 3 类
- 极客深色：矩形 + 霓虹 = 2 类
- 学生笔记：手绘 + 下划线 = 2 类

---

## Bug 6：内容传达不清（追加）

**症状**：
- 用户看完图不知道在讲什么
- 重点不突出
- 节奏混乱（不知道先看哪）

**修复**：
1. 每张图必须有**一个核心信息**（"这一页只讲一件事"）
2. 视觉层级：标题 > 核心 > 辅助 > 装饰
3. 用框/色块/箭头引导阅读顺序

---

## Bug 7：emoji 显示异常（追加）

**症状**：
- emoji 不显示 / 显示成方块
- emoji 与风格不搭（极客深色里用 🌸）

**修复**：
1. 指定 emoji 类型（如"用手绘表情符号 😅 🧠"）
2. 极客深色用 💻 ⚡ 🔥 类
3. 暖色手绘用 🪞 🧠 💡 😅 🐛 类
4. 学生笔记用 ⭐ 📌 ✏️ 📚 类

---

## 审稿 checklist

每张图必查（30 秒过一遍）：

```
□ 标题清晰、不被裁切
□ 字号合适（重点突出）
□ 代码（如有）单词拼写正确
□ 颜色与锚图一致
□ 装饰元素不超过 3 类
□ emoji 合适、不滥用
□ 一张图一个核心信息
□ 阅读顺序清楚
□ 不超出 3:4 竖版边界
```

**通过率 < 100% 就重做**——不要交付不完美的图。

---

## 重做策略

如果出图有问题：

1. **小问题**（一处文字溢出、单个 emoji 错位）：重做这一张
2. **中问题**（代码错乱、风格部分跑偏）：调整 prompt 重做
3. **大问题**（整组风格都跑偏、整体不统一）：全部重做 + 重新锚定风格

**重做不要无限循环**：3 次重做后还不行，就**接受现状** + 在 prompt 里强调"风格"约束，然后继续下一步。

## 配套正文常见问题

| 问题 | 修复 |
|------|------|
| 标题没钩子 | 加数字反差或场景共鸣（"50 行 vs 5 行"） |
| 正文太干 | 加 1-2 句自嘲或反转 |
| 标签太少 | 加 5-10 个相关标签（系列号 + 主题 + 通用 + 长尾） |
| 没评论钩子 | 加 1 句引导评论的话（"要的扣 1"） |
| 没说发布时间 | 提醒用户晚上 8-10 点发布（算法号黄金时段） |
