# Caption Box 规范

## 为什么这是核心

**没有 caption box 的 manga 一定"叙事断裂"。**

本次（音乐节 v1）踩过的最大坑：8 张图全部用画面叙事，没有 narrator 旁白，
观众单独看任一页都看不懂在讲什么。必须用 v2 + 重跑 P3 才解决。

Caption box = 每页底部的 narrator 旁白框，作用是：

1. **独立可读**：用户单看这一页就能 get 一个小节在讲什么
2. **承接上文**：让 8 页的叙事链不会被遗忘
3. **情绪定调**：旁白文案决定这页的情绪温度

## Caption Box 视觉规范

```
+--------------------------------------------------+  ← 黑色边框 2-3px
| 旁白原文。手写感中文。1-2 句。30-60 字。          |  ← 浅奶白底 #F5F0E6
+--------------------------------------------------+

高度约占页面 1/8
位置在页面最底部（不能在画面里被遮）
文字左对齐，留白均匀
字号 16-20pt（与画面中其他文字一致）
```

**绝对不要**：

- 圆角气泡型（那是角色对白）
- 透明 / 半透明（会看不清字）
- 居中（旁白是叙事声，不是喊话）
- 紫色 / 黄色等花哨背景色

## 旁白文案设计原则

### 长度

- 1-2 句，30-60 字
- 短而有力，不要 100+ 字长段落
- 8 页的旁白连起来是一段完整的内心独白

### 视角

- **第一人称**（"我"），不是"这个人"
- 现在的视角（事后回忆），不是当下视角
- 偶尔可破墙（"我见到了 TB。下次还要继续去"），但克制

### 情绪曲线（8 页为例）

| 页   | 情绪温度 | 旁白语气             |
| ---- | -------- | -------------------- |
| P1   | 期待     | 平铺直叙、悬念       |
| P2   | 行动     | 简短、节奏感         |
| P3   | 回忆切入 | 慢下来、感伤         |
| P4   | 低谷+治愈 | 转折、对比           |
| P5   | 蓄势     | 简洁、动作           |
| P6   | 高潮     | 情感爆发、留白       |
| P7   | 尴尬+成长 | 自嘲、肯定           |
| P8   | 圆梦     | 释然、开放（破墙）   |

### 句式节奏建议

- 短句 + 长句交错
- 关键句用"是..."句式（"是《you'll see》第一次让我停下来"）
- 结尾句可有"。"或"（轻装上阵。）"等补充说明
- 不用感叹号（吼）
- 不用 emoji

## 8 页旁白示例（音乐节 v2）

```
P1: 为了见 TB，我一个人去了三天音乐节里唯独买的这天
P2: 5 月 5 号早上 8 点。我搭上了去音乐节的接驳车。TB 还没开始，我已经在等了
P3: 大二上，我暗恋 ayl。是 TB 的《you'll see》第一次让我停下来
P4: 那段日子，我手足无措、什么都做不了。是《铁之贝克》一句句歌词流进来，把低谷的我拉起来
P5: 到了现场，我铺了野餐垫、充好气沙发。但我心里只有一个念头——TB 什么时候出来
P6: 他们出现了。20 分钟、3 首歌。我意识到，我爱的、我想到的，都可以是真的
P7: 搭讪很尴尬，烈日把人烤熟。但对一个社恐来说，主动开口这件事本身，就是一次巨大进步
P8: 我见到了 TB。不是屏幕里的他们，是真实的、可以触摸到的。下次还要继续去。（轻装上阵。）
```

## 对白 / 拟声词设计（可选，补充 caption 用）

caption 是 narrator，对白是角色说话。两者不冲突：

```
- caption: "我搭上了去音乐节的接驳车"
- 对白:    角色小声："走吧。"（拟声: 引擎 ブーン）
```

设计原则：

- 对白要少，**caption 才是主叙事**
- 拟声词用粗体黑手写体（咚 / 哐当 / グルグル / シーン）
- 拟声词可在画面里放大作为视觉元素
- 不要每页都对白，留白呼吸

## 出版级 caption 自检

出图后检查：

- [ ] caption 文字真的在 box 里、清晰可读？
- [ ] 8 页连起来是 1 段完整的内心独白？
- [ ] 每页 caption 都能独立成立？
- [ ] 没有出现"我"以外的人称混乱？
- [ ] 没有错别字 / 语病 / 重复句式？
- [ ] 没有 emoji / 感叹号 / 网络用语？
- [ ] 最后一页是否"破墙"或留白（结束感）？
