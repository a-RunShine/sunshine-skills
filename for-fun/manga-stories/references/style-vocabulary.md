# Manga 风格关键词库

按"想画什么感觉"反查关键词组合。不用死记，挑需要的塞进 prompt 即可。

## 风格参考（写进 prompt 用）

| 风格名          | 关键词                                              | 适用场景              |
| --------------- | --------------------------------------------------- | --------------------- |
| 青春摇滚        | 浅野いにお SOLANIN, 孤独ロック (BOCCHI THE ROCK)    | 暗恋、追星、校园乐队  |
| 治愈日常        | 群ようこ, ほしのこえ                                  | 治愈、日常、慢生活    |
| 戏剧化 / 写实   | 井上雄彦 SLAM DUNK, 浦沢直樹 MONSTER                | 体育、悬疑（不推荐默认）|
| 极简 / 童话     | やなせたかし, 谷口治郎                                | 极简、童话、萌系      |
| 复古 / 昭和     | 梶原一骑, 永井豪, 70s-80s 日漫                       | 复古、致敬、怀旧      |
| 少女 / 恋爱     | 高梨三葉, 椿いづみ                                    | 少女、恋爱、纯情      |
| 黑色 / 成人向   | 伊藤潤二, 押切蓮介                                    | 恐怖、悬疑、压抑      |

## 线条与画风

| 想要的感觉       | 关键词                                                       |
| ---------------- | ------------------------------------------------------------ |
| 干净、克制       | clean line, minimal cross-hatching, white space dominant     |
| 手绘感、粗糙     | rough sketch, uneven line weight, hand-drawn feel            |
| 复古 / 胶片感    | vintage 70s, slightly worn lines, film grain                |
| 漫画式夸张       | exaggerated expressions, dynamic poses, speed lines heavy    |
| 写实、细腻       | detailed cross-hatching, dramatic shadows, photorealistic    |

## 上色策略

| 策略             | 关键词                                                       | 适用               |
| ---------------- | ------------------------------------------------------------ | ------------------ |
| 纯黑白           | pure black-and-white, screentone only, no color              | 完整故事、严肃     |
| 黑白+局部色      | B&W with selective color, watercolor wash, accent on mood    | 推荐默认（1-3 页） |
| 单色辅助         | monochrome duotone (apricot + black)                         | 统一情绪           |
| 复古双色         | vintage duotone (pink + black, or blue + cream)              | 少女、治愈         |
| 全彩             | full color, digital painting style                           | 不推荐默认（失去 manga 感）|

## 推荐色板

### 暖色（治愈 / 怀旧）

```
apricot       #E8B57E   暖橙，舞台光、夕阳
dusty pink    #E5B5B5   旧粉，脸红、记忆
cream         #F5F0E6   奶白，背景底、caption box
sepia         #8B6F47   棕褐，阴影、回忆
soft yellow   #F2D88A   柔黄，灯、光斑
```

### 冷色（清醒 / 治愈的另一面）

```
blue-gray     #B8C5D6   蓝灰，晨光、安静
dusty teal    #6A8A87   灰绿，树木、阴凉
soft lavender #C9B8D9   淡紫，回忆、梦境
pale rose     #D4A5A5   苍粉，脆弱、温柔
ink black     #2A2A2A   墨黑，线稿、主色
```

### 节制用色（不要全用）

8 页里**只用 1-2 个色系**，不要冷暖混搭。
推荐：apricot + dusty pink + cream（暖系治愈）

## 人物简化

| 风格档      | 描述                              | 关键词                                                |
| ----------- | --------------------------------- | ----------------------------------------------------- |
| 极简火柴人  | 圆头 + 直线身体                   | stick figure, round head, no hair, dot eyes           |
| 简化漫画    | 圆头 + 简单身材 + 简化发型         | simplified manga character, minimal body, color-block hair |
| 完整漫画    | 详细身材 + 发型 + 表情             | full manga character, detailed face, hair detail     |
| 写实        | 真人级                            | photorealistic, real human, detailed                 |

**默认用"简化漫画"**——本次音乐节 v2 实测 AI 表现最好。

## 格子（panel）布局变化

不要每页 2×2。建议 8 页至少用 3 种不同的 layout：

### Layout A：1 大 + 3 小（推荐 P1/P6 高潮页）

```
+----------------------+
|        大格          |
+----------+-----------+
|   小格   |    小格   |
+----------+-----------+
|        小格          |
+----------+-----------+
```

### Layout B：横长 + 竖长（推荐 P2/P5 行动页）

```
+----------------------+
|       横长格          |
+----+-----------------+
| 竖 |                 |
| 长 |     大格        |
| 格 |                 |
+----+-----------------+
```

### Layout C：电影宽屏 + 2 中（推荐 P7 尴尬/自嘲）

```
+-----------------------------+
|       电影宽屏格            |
+------------+----------------+
|    中格    |     中格       |
+------------+----------------+
```

### Layout D：垂直 4 格（推荐 P3 回忆切入）

```
+--------+
|  格1   |
+--------+
|  格2   |
+--------+
|  格3   |
+--------+
|  格4   |
+--------+
```

## 拟声词 / 视觉细节

| 场景           | 拟声词                              |
| -------------- | ----------------------------------- |
| 引擎 / 启动    | ブーン, ブブー, 嗡                   |
| 心跳           | ドキドキ, 咚咚                       |
| 沉默 / 安静    | シーン, 静, ...                      |
| 撞击 / 摔倒    | ガシャン, ドカン, 啪                |
| 风吹 / 翻页    | サラサラ, 沙沙                       |
| 舞台轰鸣       | ドドド, 轰轰                        |
| 烈日           | ギラギラ, 灼灼                      |
| 灯光闪烁       | キラーン, 闪                         |

AI 倾向加日式拟声词（这是好事），但要确认中文 caption 也能正确渲染。

## 真实人物 / 乐队 / 明星的处理

**默认不画真实人物**——可能侵权，也容易画走样。用符号代替：

| 真实对象       | 符号代替                                             |
| -------------- | ---------------------------------------------------- |
| 真人乐队       | 舞台 + 灯光 + 3 个剪影 + 简化乐器轮廓               |
| 真人明星       | 远景剪影 + 闪光灯海 + 招牌动作符号                   |
| 真人偶像       | 海报 + 签名 + 周边物品（荧光棒、扇子）               |
| 真实地标       | 标志性元素（塔尖、招牌文字简写）而不是建筑全貌        |
| 用户本人       | 圆头简化漫画人物（不画脸的具体五官）                  |
| 用户的暗恋对象 | 圆头简化漫画人物（可以画发色或衣服区分，但不画脸）   |

**例外**：用户明确授权"画 XX 本人" + 提供照片 reference + 接受可能画走样的风险。
