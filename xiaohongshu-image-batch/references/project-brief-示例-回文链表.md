## 关键经验（这次踩过的坑）

1. **/grilling 红线**：一次问一个问题 + 给推荐答案。**之前我一次甩 4 个问题属于 "bewildering"，错的**。
2. **Gemini 渲染代码经常乱码** —— 第一次出图 Java 关键字全是乱字符（`Lavetope`、`Reilnewrten`）。修复：重做时把完整代码贴进 prompt + 强调"按字生成、不能多字少字、不能拼错英文单词"。
3. **第一次出图风格割裂** —— 封面是极客深色、内容页是暖色手绘，反差过大。修复：封面单独定调，按锚图色板统一底色。
4. **封面是单独决策点** —— 不与内容页混着出，要更夸张但底色统一。
5. **grill 不可跳过** —— 用户给的细节越少，跑偏越严重。这次走了 10 题 grill 才出图，出来的 7 张图风格统一不割裂。
