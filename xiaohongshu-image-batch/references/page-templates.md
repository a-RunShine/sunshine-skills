# 页型模板（Page Templates）

8 类页型 + 通用 prompt 骨架。每个页型都有"职责 / 必备元素 / 骨架 prompt"三段。

---

## 页型 1：封面（Cover）

**职责**：抓住注意力、传达核心梗、决定点开率

**必备元素**：
- 顶部系列号标签（"带你刷 XXX" 或 "XX 期 #234"）
- 大字标题（核心反差/悬念/数字对比）
- 副标（这期主题）
- 主视觉对比（左右 / 上下 / 框中框）
- 底部金句 + 下滑箭头

**骨架 prompt**（带代码版）：
```
[风格规范]
顶部系列号 [XXX #XX]
大字标题 [核心梗，如 "我 50 行 vs 大佬 5 行"]
副标 [主题]
主视觉：[左大代码框 / 右小代码框，对比反差]
- 左代码框（占 60%）：[完整方法 1 代码]
- 中间 VS 大字
- 右代码框（占 35%）：[完整方法 N 代码]
底部金句 [一句话总结] + 下滑箭头
```

**骨架 prompt**（不带代码版）：
```
[风格规范]
顶部系列号 [XXX #XX]
大字标题 [核心观点]
副标 [主题]
主视觉：[左右/上下对比，如"理想 vs 现实"或"前 vs 后"]
底部金句 + 下滑箭头
```

## 页型 2：官方题目（Official Task）

**职责**：列出题目描述、示例、约束、进阶要求

**必备元素**：
- 顶部标签（题号 + "官方题目"）
- 大字标题
- 题目描述方框
- 示例 1、2
- 约束方框
- 进阶方框（**关键钩子**）
- 底部标签（难度 + 标签）

**骨架 prompt**：
```
[风格规范]
顶部手绘标签 [LeetCode XX · 官方题目]
大字标题 [主题]
中部手绘圆角方框：
- 题目描述：[题干原文]
- 示例 1：[输入] → [输出]
- 示例 2：[输入] → [输出]
小手绘方框 [⚠️ 约束]：[数据范围]
奶油黄高亮方框 [🔥 进阶]：[进阶要求，为后续铺垫]
底部标签 [难度 · 标签]
```

## 页型 3：科普铺垫（Concept Primer）

**职责**：让小白看懂这是什么问题

**必备元素**：
- 大字标题（"什么是 XXX？"）
- 可视化（链表示意 / 树形 / 图示 / 流程图）
- 正反例对比
- 一句话总结

**骨架 prompt**：
```
[风格规范]
大字标题 [什么是 XXX？]
中部 [可视化元素，如两条链表对比]
- 上方 [正例，✅ 标注]
- 下方 [反例，❌ 标注]
底部手绘方框 [一句话总结规则]
```

## 页型 4：方法 1 / 笨办法

**职责**：展示最朴素/最直觉的解法，建立"对比基线"

**必备元素**：
- 标题（"方法 1 · XXX"）
- 副标（**自嘲/铺垫**，如"我凌晨 3 点的解法 😅"）
- 三步流程（手绘方块 + 箭头）
- 代码块（**完整**）
- 复杂度（时间 / 空间）
- 自嘲话术

**骨架 prompt**：
```
[风格规范]
标题 [方法 1 · XXX]
副标 [自嘲话术] + [emoji]
中部三步流程（手绘方块 + 箭头）：
① [步骤 1] → ② [步骤 2] → ③ [步骤 3]
下方黑底代码框（macOS 红黄绿圆点）：
[完整方法 1 代码，逐字生成]
底部 [时间 O(?) | 空间 O(?)]
底部小字 [面试官评语，能 AC 但不是最优]
```

## 页型 5：方法 N / 巧办法

**职责**：展示最优解 / 巧办法

**必备元素**：
- 标题（"方法 N · XXX"）
- 副标（**惊艳/反转**，如"大佬 5 分钟的解法 🧠"）
- 三步流程（手绘方块 + 箭头）
- 代码块（**更短**）
- 复杂度（带 ⭐ 强调最优）
- 反转话术

**骨架 prompt**：
```
[风格规范]
标题 [方法 N · XXX]
副标 [惊艳话术] + [emoji]
中部三步流程：
① [步骤 1] → ② [步骤 2] → ③ [步骤 3]
下方黑底代码框：
[完整方法 N 代码，逐字生成]
底部绿色高亮 [时间 O(?) | 空间 O(?) ⭐]
底部小字 [面试官评语，这才是最优解]
```

## 页型 6：复杂度对比（Compare Table）

**职责**：让方法 1 vs 方法 N 的优劣一目了然

**必备元素**：
- 大字标题（"为什么偏爱方法 N？"）
- 表格（手绘风、圆角）
- 红× 标注次优 / 绿✓ 标注最优
- 关键金句

**骨架 prompt**：
```
[风格规范]
大字标题 [为什么偏爱方法 N？] + 💡 emoji
中部手绘圆角表格：
| 方法 | 时间复杂度 | 空间复杂度 |
| 方法 1 XXX | O(?) | O(?) ❌ 红× |
| 方法 N XXX | O(?) | O(?) ✅ 绿✓，整行淡绿高亮 |
底部方框 [💡 O(?) 空间 = 关键优势]
底部金句 [一句话总结]
```

## 页型 7：万能模板（Universal Pattern）

**职责**：抽象出可复用的解题套路 / 收尾收藏钩子

**必备元素**：
- 标题（"XXX · 万能 N 步模板"）
- 大框（容纳 N 步）
- N 步法（每步前面带圆形序号）
- 一句话口诀
- 适用场景
- 收藏钩子

**骨架 prompt**：
```
[风格规范]
标题 [XXX · 万能 N 步模板] + 📌 emoji
中部大手绘框：
- 顶部小标签 [N 步法]
- ① [步骤 1]（[具体技术]）
- ② [步骤 2]（[具体技术]）
- ③ [步骤 3]（[具体技术]）
底部一行超大口号 [步骤 1 → 步骤 2 → 步骤 3]
下方 [适用场景]
底部 [🌙 收藏起来，下次遇到直接套]
```

## 页型 8：配套正文（Copywriting）

**职责**：发布时复制的文字

**结构**：
- 标题（带钩子 / 系列号 / 数字反差）
- 开头钩子（3-5 行）
- 核心内容（5-10 行）
- 收尾金句
- 评论区置顶
- 标签（5-10 个）

**骨架**：
```
[系列号] #XX｜[核心钩子]

[系列号第 X 期 · 主题 emoji]

[开头 3-5 行：背景或反差]
- 自嘲/震惊/共鸣

[核心 5-10 行：方法/原理/金句]
- 对比 / 数字 / 套路

[收尾 1-2 行：万能模板 / 收藏钩子]

#[tag1] #[tag2] #[tag3] ...
```

**评论区置顶模板**：
```
代码太长放不下了，整理成完整笔记了，
要的扣 1，下期更新 XXX
```

## 通用 prompt 模板

每张图的 prompt 都按这个结构组装：

```
[1. 风格规范]  ← 从 style-cookbook.md 抄
[2. 主题]      ← 从 grill-me 答案填
[3. 页型]      ← 从本文件选
[4. 内容]      ← 用户素材
[5. 特殊要求]  ← 如"代码逐字生成"、"emoji 用手绘圈圈"
[6. 比例]      ← 3:4 竖版
[7. 分辨率]    ← 2K
```

⚠️ **不要省略第 1 项风格规范**——这是防止风格跑偏的关键。
