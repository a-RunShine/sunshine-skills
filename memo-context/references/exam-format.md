# 考研英语阅读出题标准速查

> 来源：考研英语大纲、历年真题统计、主流教辅（新东方/中公/跨考/海文）。本文件用作 memo-context **D 模式（考研阅读）** 的写作与命题参考。

---

## 1. 试卷位置与权重

| 项 | 详情 |
|---|---|
| 试卷满分 | 100 分 |
| 阅读 Part A 分值 | 40 分（4 篇 × 5 题 × 2 分）—— **全卷最重** |
| 词数 | 英语一：4 篇 ≈ 1600 词，单篇约 400 词；英语二：4 篇 ≈ 1500 词，单篇 < 400 词 |
| 生词 | 英语一允许 ≤3% 超纲词（≈12-15 词/篇）；英语二无超纲 |
| 题量 | 20 道四选一 |

## 2. 文章体裁与来源

- **体裁**：以 **说明文 + 议论文** 为主，社会科学占比最重（经济学、心理学、教育学、社会学），自然科学次之（医学、生物、工程、科学史），人文近年上升。
- **来源**（80% 命中区间）：经济学人 The Economist、卫报 The Guardian、自然 Nature、科学美国人 Scientific American、新闻周刊 Newsweek、纽约时报 New York Times、时代周刊 Time、基督教科学箴言报 Christian Science Monitor、大西洋月刊 The Atlantic、麦肯锡季刊 McKinsey Quarterly、哈佛商业评论 HBR。
- **时效性**：通常选近 2-3 年的文章。

## 3. 文章结构特征

- **段落数**：3-6 段为常见区间。
- **题文同序**：约 60% 准确度——题目顺序大致对应段落顺序（细节题尤其稳定）。
- **主旨出现位置**：
  - 常见：首段首句 / 末段末句 / 前两段转折之后
  - 较难：整篇不直接给中心，需要归纳
- **过渡特征**：however / yet / but / although / while 等转折词密集；总分总、对比-让步、现象-原因-解决方案 是常见骨架。

## 4. 六大题型（命题模式）

### 4.1 主旨大意题
- **题干标志**：best title / main idea / mainly discuss / mainly deal with / the author intends to / purpose / conclusion
- **答案特征**：能覆盖全文、不含细节性名词、不含过分绝对词。
- **干扰项**：以偏概全、只覆盖局部、出现具体细节名词、过于笼统到与文章无关。

### 4.2 细节题（占最重，英语二约 30 分）
- **题干标志**：According to... / which of the following is true / ...because / 5W1H
- **解题思路**：关键词定位原文 → 同义替换匹配。
- **核心技巧**：注意比较级、绝对词、否定前缀；警惕张冠李戴、范围扩大/缩小、时态偷换。

### 4.3 推理判断题
- **题干标志**：infer / imply / suggest / conclude / It can be learned that...
- **答案特征**：**绝大多数是原文某句的同义改写**，**不**是大幅逻辑跳跃。
- **核心原则**：「不要想得太多，推得太远」。过度推断 = 错误。

### 4.4 词义/句意题
- **题干标志**：The word "..." (in line X) is closest in meaning to... / refers to... / The phrase "..." most probably means...
- **解题思路**：看上下文逻辑关系、同义复现、词根词缀、对立/因果信号词。
- **干扰项**：与所考词形似但义远、考熟词时常规义反而错、解释里含过多原句字眼的多为错。

### 4.5 态度观点题
- **题干标志**：The author's attitude toward... / ...is one of... / deem / consider / tone
- **答案类型**：
  - 积极：approval / supportive / favorable / praising / optimistic / appreciative / affirmative
  - 消极：disapproval / critical / pessimistic / skeptical / concerned / questioning / indifferent
  - 中立：neutral / impartial / objective
- **解题技巧**：看转折词、情态动词（may/would/should/could）、情感色彩形容词副词。
- **干扰项**：他人观点冒充作者观点、过于绝对、文章中未明说、与主题相反。

### 4.6 例证题（英语一特有，英语二很少考）
- **题干标志**：The example of... illustrates / ...is mentioned to / ...demonstrates
- **核心原则**：例子本身**不重要**，**例子前面的观点句才是答案**。例子看不懂没关系，往前找观点。

## 5. 干扰项六大特征（出题人惯用伎俩）

| 类型 | 手法 | 例子 |
|---|---|---|
| **偷换概念（张冠李戴）** | 偷换主语、动作发出者/承受者、动作本身、范围、时态、极性（正反颠倒） | 原文主语 employer → 选项改 one（雇员） |
| **望文生义** | 选项仅 1-2 词出现在定位句，其余表达文中无据 | 凭空给某名词加文中不存在的动宾搭配 |
| **细节杂糅** | 把不同句子的单词拼成一个选项，修饰关系却对不上 | 跨句拼凑，逻辑断裂 |
| **因果倒置** | 把原因说成结果，或反之 | "A 导致 B" → "B 导致 A" |
| **答非所问** | 文中提到但答错问点 | 题问作者态度，选项讲他人态度 |
| **无中生有** | 完全捏造，原文无此信息 | 杜撰概念、引用不存在的数据 |

**辅助技巧**：
- 删减法 / 调序法 / 替换法 / 缺漏法 / 添加法（设题技术层面）
- 中外思维差异：**some / perhaps / seem / about / probably** 常为正确；**certainly / extremely / never / must** 常为错误

## 6. 写作风格参考（D 模式产出模板）

要让产出文章**像考研真题原文**，模仿来源刊物的写作风格：

| 维度 | 特征 |
|---|---|
| **句法** | 从句嵌套多，长句占比高（每段 2-3 个长难句），多处定语/状语后置 |
| **用词** | 学术化抽象名词（phenomenon / perception / institution / prevalence / assumption），低频形容词（plausible / contentious / pronounced）|
| **人称** | 极少第一人称叙述，多为客观/第三人称分析 |
| **逻辑词** | however / yet / but / while / although / meanwhile / consequently / nevertheless 高频 |
| **结构** | 总分总 / 现象→原因→影响→应对 / 对比→让步→结论 |
| **回避** | 口语化缩写（don't / can't）、俚语、感情化形容词、感叹句、第二人称 |

**生词密度**：每 400 词允许 1-2 个生词（≥6 级/低频 GRE 词），但必须从上下文可推断。

## 7. memo-context D 模式产出规范

### 7.1 文章要求
- **词数**：550-650 词（贴近英一单篇真题长度上限）
- **段落数**：4-5 段
- **覆盖**：13 主线词 × 2-3 次，15 配角词 × 1 次
- **风格**：模仿经济学人/卫报议论文，长句 + 抽象名词 + 转接连词
- **题材**：自选社科/教育/医学/伦理/科技 等"考研友好"主题

### 7.2 题目要求（5 道四选一）
按以下顺序出 5 题（标准 6 类精炼版）：

1. **主旨大意题**（1 道）— 题干用 `The passage is mainly about` / `Which of the following best summarizes the passage`
2. **细节题**（1 道）— 题干用 `According to Paragraph X, ...`
3. **推理题**（1 道）— 题干用 `It can be inferred that` / `The author implies that`
4. **词义题**（1 道）— 题干用 `The word "..." (in line X) is closest in meaning to`
5. **态度题**（1 道）— 题干用 `The author's attitude toward ... is one of`

### 7.3 干扰项构造要求
- **每题必须 1 个正确选项 + 3 个干扰项**
- 干扰项必须用至少 2 种本章第 5 节列出的干扰手法（偷换概念 / 无中生有 / 以偏概全 / 因果倒置）
- 正确选项应是原文某句的**同义改写**，不直接照抄
- 绝对化词（certainly / never / always / must）放错误选项，缓和词（may / perhaps / seem）放正确选项

### 7.4 答案与解析格式

每题在文末给出：
```
【答案】X
【解析】①定位句位置 ②正确选项的同义替换 ③干扰项如何设陷阱
```

### 7.5 TTS 注意
- **只朗读文章，不朗读题目**（题目与答案供用户事后练习用）
- 速度 0.9（清晰度优先于节奏）

## 8. 实战生成 Prompt 模板（给 D 模式 prompt 调用）

```
你是考研英语阅读命题人。生成一篇 600 词左右的英一 Part A 阅读文章 + 5 道四选一。

主题：{主题}（建议社科/教育/医学伦理/科技政策类，避开政治与中美国情）

强制词表（必须自然融入）：
{13 个主线词} — 每个出现 2-3 次
{15 个配角词} — 每个出现 1 次

风格要求：
- 句法：模仿经济学人/卫报，长难句占比 ≥ 30%
- 用词：学术抽象名词 + 偶尔 1-2 个低频词
- 段落：4-5 段，总分总结构，转折词密度高
- 生词密度：≤ 3%

5 题顺序与模板：
Q1 主旨大意 (The passage is mainly about...)
Q2 细节定位 (According to Paragraph X, ...)
Q3 推理判断 (It can be inferred that...)
Q4 词义猜测 (The word "..." in line X is closest in meaning to)
Q5 态度观点 (The author's attitude toward ... is one of)

每题 1 个正确选项 + 3 个干扰项，干扰项必须用 ≥ 2 种手法（偷换概念/无中生有/以偏概全/因果倒置）。
正确选项用同义改写，不直接抄原句。
答案与解析另起一节。

输出格式（Markdown）：
## Passage
[文章]

## Questions
1. ...
[A] ...
[B] ...
[C] ...
[D] ...
... 5 题

## Answer Key & Analysis
1. 【答案】X 【解析】...
...
```
