# 学霸标注风格指南（混合派）

> **混合派** = 考试派打底（每段每词必出）+ 记忆派补充（关键难词加 1 个口诀）。
> 目的：考研/应试场景下，考点清晰 + 难词秒记，**严肃专业但有温度**。

---

## 1. JSON Schema

```jsonc
{
  "date": "2026-08-04",                  // 必填，存档日期
  "mode": "D",                            // A | B | C | D
  "title": "算法治理 vs 公共信任危机",     // 必填，文章标题（用于 header）
  "word_count": 13,                       // 主线词数
  "supporting_count": 16,                 // 配角词数
  "main_words": ["presumably", "..."],    // 主线词表（按选词顺序）
  "supporting_words": ["...", "..."],     // 配角词表
  "paragraphs": [
    {
      "id": 1,                            // 段号（1-indexed，匹配 article.md 段落顺序）
      "focus_words": ["crisis", "..."],   // 本段出现的重点词（主线优先）
      "cards": [                          // 每段 1-3 张卡（考试派为主，记忆派补充）
        {
          "type": "exam",                 // 必填：exam | memo
          "word": "crisis",               // 标注对应的词
          "title": "考点·搭配",           // 卡片标题，简洁精准
          "content": "n. 危机, 危急关头<br>· legitimacy crisis 合法性危机<br>· ..."
        },
        {
          "type": "memo",
          "word": "crisis",
          "title": "记忆口诀",
          "content": "谐音「<b>快-累-死</b>」= 危机压顶<br>联想: ..."
        }
      ]
    }
  ]
}
```

### 字段约束

- `id` 必须 1-indexed 且**与 article.md 段号一一对应**（article.md 段间空行分隔，顺序计数）
- `cards` 数量：1 段 1-3 张（**考试派至少 1 张**，记忆派 0-1 张，只给关键难词）
- `content` 支持 inline HTML：`<br>` 换行、`<b>...</b>` 加粗、避免其他标签
- 每段重点词数 ≈ 主线词在该段的出现数（1-3 个）
- **JSON 顶层不要带 comments**（生产渲染用 `json.load`）

## 2. 卡片类型

### 2.1 考试派 (`type: "exam"`)

> **目的**：应试场景下能秒答考点。严肃、专业、信息密集。

**6 种模板**（按词性/场景挑一种）：

| 模板 | 适用 | 标题示例 | 内容骨架 |
|---|---|---|---|
| **考点·搭配** | 任何词 | 考点·搭配 | `pos. 释义<br>· 搭配1 翻译<br>· 搭配2 翻译<br>· 复数/不规则变化: ...` |
| **考点·构词** | 派生/合成词 | 考点·构词 | `pos. 释义<br>· 前缀/词根/后缀 = 含义<br>· 派生: n./adj.<br>· 搭配` |
| **考点·辨析** | 易混词 | 考点·辨析 | `pos. 释义<br>· 近义 A: 区别<br>· 近义 B: 区别<br>· 选词: A 用于... / B 用于...` |
| **易混对比** | 形近/音近 | 易混对比 | `adj. 释义<br>· 正确用法<br>· 常见错误: X ≠ Y (X 错在哪)<br>· 派生` |
| **考点·时态** | 动词 | 考点·时态 | `v. 释义<br>· 时态: did/done/doing<br>· 语态: 主动/被动<br>· 常见搭配` |
| **考点·频考** | 高频考点词 | 考点·频考 | `n. 释义<br>· 写作模板: ... is a key factor in ...<br>· 阅读信号: 出现 = 文章讲...` |

**内容硬约束**：
- 至少 2 行内容（不允许只写释义）
- 至少 1 个**具体搭配**（不是泛指）
- 不要写"详见词典"这种无信息内容

### 2.2 记忆派 (`type: "memo"`)

> **目的**：让难词**用一次就记住**。轻松、有画面感、可口播。

**5 种模板**（按词选一种）：

| 模板 | 适用 | 标题示例 | 内容骨架 |
|---|---|---|---|
| **谐音口诀** | 难记拼写 | 谐音口诀 | `谐音「XX」= 联想画面<br>例如: ...` |
| **词根串联** | 有清晰词根 | 词根串联 | `词根 XX- = 含义<br>· 派生 A = ...<br>· 派生 B = ...` |
| **画面联想** | 抽象词 | 画面联想 | `想象一个场景: ...<br>看到 X = 想到本词` |
| **对比速记** | 与近义词 | 对比速记 | `A vs B:<br>· A = 强/正/...<br>· B = 弱/负/...<br>记口诀: ...` |
| **搭配口诀** | 高频搭配 | 搭配口诀 | `记口诀: X + Y = Z 含义<br>例: X Y Z = ...` |

**内容硬约束**：
- 必须有"画面/口诀/串联"具体内容（不是空话）
- 谐音必须**真谐音**（发音接近，不是硬造）
- 词根必须是**真词根**（来源是拉丁/希腊/古英语）

## 3. LLM Prompt 模板

> **Step 5.5 调 LLM 时用这个 prompt**。复制粘贴，替换 `{{...}}` 变量。

```
你是「墨墨学霸笔记」的标注员，给一段 {{MODE}} 模式的英文阅读材料生成"混合派"标注。

# 任务
对每段（{{N_SEGMENTS}} 段）的重点词（{{MAIN_WORDS}} 主线，{{SUPPORTING_WORDS}} 配角），
生成 1-3 张标注卡：
- 每段至少 1 张"考试派"（type: "exam"），覆盖该段最重点的 1-2 个词
- 如果该段有"难记/难拼/易混"的词，加 1 张"记忆派"（type: "memo"）
- 不为配角词单独出卡（它们只出现在考试派的搭配里）

# 输入
## 文章
{{ARTICLE_TEXT}}

## 主线词（必出）
{{MAIN_WORDS_COMMA_SEPARATED}}

## 配角词（可选）
{{SUPPORTING_WORDS_COMMA_SEPARATED}}

# 输出格式
严格输出 JSON，**不要 markdown 代码块包裹**，**不要解释**。schema 见 references/annotation-style.md § 1。

# 风格
- 考试派：严肃专业，2-4 行内容，必有 1 个具体搭配
- 记忆派：轻松有画面，谐音是真谐音，词根是真词根
- 中文为主，专有名词保留英文
- 避免"详见词典""常用词"等无信息内容
- inline HTML 只用 <br> 和 <b>...</b>

# 自我检查（生成后默念一遍）
□ 每段都有考试派？
□ 关键难词都有记忆派？
□ 卡片数量 1-3 张/段？
□ 谐音/词根我确认过是真的？
□ 没有任何 markdown 包装？
```

## 4. 视觉风格（与 HTML 渲染对齐）

> 这是给 **HTML 渲染端**看的，LLM 不用关心。

| 维度 | 考试派 (`exam`) | 记忆派 (`memo`) |
|---|---|---|
| **亮色底** | `#fef5e7`（米黄） | `#e8f4f8`（浅蓝） |
| **暗色底** | `#3a2f1f`（暗橙棕） | `#1f3a40`（暗青） |
| **左边框** | `#e67e22`（暖橙）| `#2980b9`（钢蓝） |
| **图标** | 📚 考试派 | 💡 记忆派 |
| **徽章** | "考试派" | "记忆派" |

> **暗色模式特殊处理**：段落的重点词 `<em>` 不用黄底，**改用暖琥珀色波浪下划线**（避免"白字黄底"违和感）。标注卡保持原色系（暗色版用更暗的同色调）。

## 5. 反例（不要这样写）

❌ **考试派空话**：
```json
{"type": "exam", "word": "good", "title": "释义", "content": "adj. 好的"}
```

❌ **记忆派硬造谐音**：
```json
{"type": "memo", "word": "crisis", "title": "谐音", "content": "crisis = 可瑞思（没有任何帮助）"}
```

❌ **配角词也单独出卡**：
```json
{"type": "exam", "word": "grain", "title": "...", "content": "..."}  // grain 是配角，不应单独出
```

❌ **markdown 包装**：
```
```json
{"date": "..."}
```
```

✅ **正确示例**：
```json
{"type": "exam", "word": "crisis", "title": "考点·搭配", "content": "n. 危机, 危急关头<br>· legitimacy crisis 合法性危机<br>· economic crisis 经济危机<br>· 复数: <b>crises</b> /ˈkraɪsiːz/"}
```

## 6. 数量速查

| 段落数 | 总卡片数（合理范围）|
|---|---|
| 3 段 | 3-7 张 |
| 5 段（D 模式默认）| 5-12 张 |
| 7 段（B 模式长文）| 7-18 张 |

> **不要为了"显得多"硬塞卡**。一段如果只有一个词需要标注，就只出 1 张。
