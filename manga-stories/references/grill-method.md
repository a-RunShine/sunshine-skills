# 内置 Grill 方法

> 这是 manga-stories 自己的 grill 流程。**不依赖外部 `grilling` skill**——
> 调用 ask_user 一次一问即可，方法论在这里。

## 核心原则

**一次一问**。不要一次性把 5 个问题摆出来让用户答。
每问只针对**一个决策**，给 2-4 个选项 + 推荐。

## 问题生成流程

```
1. 通读用户给的故事
2. 心里列出"这个故事要画好必须知道的决策"
3. 按优先级排序
4. 一次问一个，等用户答完再问下一个
5. 用户主动补充的信息（即使不在问里）也算对齐
6. 全部对齐后落档 brief.md
```

## 一次一问的格式

每次只问 1 个决策。模板：

```
[你心里想的事]
为这个故事画 manga，我想先确认 [这一个决策]。

[问题]
[一个具体的问题，2-4 个选项]

[推荐]
我倾向 [选项 X]，因为 [1 句理由]。但你想画哪种都行。

[选项]
- A：[选项 + 简短解释]
- B：[选项 + 简短解释]
- C：[选项 + 简短解释]
- Other (用户在 UI 里输入)
```

## 不要做

- ❌ 一次问 5 个决策——让用户被清单淹没
- ❌ 给 7+ 个选项——选项太多 = 不知道怎么选
- ❌ 不给推荐——只列选项让用户挑
- ❌ 问"你想要什么风格"——太开放，直接给 3 个风格 + 让用户挑
- ❌ 把整个决策池一次塞给用户
- ❌ 问用户已经说过的事（用户说"用孤独摇滚风格"就不问风格）

## 问的顺序（按优先级）

```
1. 风格细化           （如果用户没说）
2. anchor 页是哪张     （必问，影响后续所有）
3. 真实人物 / 真人     （如果有，影响符号/授权）
4. 人物设定             （火柴人 / 简化 / 写实）
5. 张数 / 系列         （默认 8 / 单期，可跳过）
6. 彩色页选哪几页      （默认 1-3 页选情绪峰值）
7. 标签 / 平台         （用户自己会写）
```

> **第 1-3 项几乎必问**，4-7 看情况。

## 决策池（按需取用）

```
[范围]    你想画整篇 / 还是挑一段 / 还是只画高潮？
[张数]    想要几页？(默认 8)
[风格]    写实漫画 / 简化 / 极简 / 复古 / 萌系？
[参考]    有没有喜欢的 manga / 漫画家风格可以参考？
[真实人物] 故事里有真人/真乐队吗？→ 决定要不要问授权
[人物设定] 你 / 故事里的人 怎么画？
[情绪锚点] 这故事里情绪最复杂 / 最想画好的是哪一页？
[系列]    是单期还是系列第一期？
[标签]    想要什么主题标签？
[彩色页] 哪几页想上色？
[平台]    准备发小红书 / 公众号 / IG？影响 caption 长度
```

## 三个典型场景的实操

### 场景 A：用户只说"画成 manga" + 给了一篇日记

**你心里知道的**：故事、情绪、可能想画哪些帧
**你不知道的**：风格细化、anchor 选哪帧、有没有真实人物

→ 问 1：风格（写实 / 简化 / 复古 / 萌系 + 推荐）
→ 问 2：anchor 页（"我看下来 [某帧] 是情绪最复杂的，你想从那页开始画吗？还是另选一页？"）
→ 问 3：如果故事里有真名乐队 / 明星 → 问授权；没有就跳过

**2-3 问搞定。**

### 场景 B：用户说"用《孤独摇滚》风格画我暗恋的同事"

**你心里知道的**：风格、题材（暗恋）
**你不知道的**：故事具体内容、anchor 选哪帧

→ 问 1：故事具体讲什么（让他先讲，不给选项）
→ 问 2：anchor 选哪帧
→ 可选问：要不要上色 / 几张

**2-3 问搞定。**

### 场景 C：用户说"想画个故事但没灵感"

→ 问 1：什么情绪？（治愈 / 燃 / 丧 / 甜 + 推荐）
→ 问 2：什么题材？（追星 / 暗恋 / 友情 / 日常 / 圆梦 + 推荐）
→ 问 3：给 2-3 个故事钩子让他挑一个
→ 问 4：风格

**3-4 问搞定。**

## 完成标准

- 用户回答完所有**当时需要的**问题
- 你心里能讲出"这个故事的 N 页大概是什么"
- 任何用户**主动补充**的（不在问题里）也记下来
- 生成 `brief.md` 把决策落档（**只落实际决策**）

## 跟外部 grilling skill 的关系

**本 skill 内置 grill 方法，不调用外部 `grilling` skill。**

外部 `grilling` skill 适合"对一个完整方案 / 决策 / 想法做 11 问 stress test"。
本 skill 的 Step 1 是"为画 manga 收集最少必要信息"，目标和方法不同。

如果你想对**画 manga 这个决策本身**做 stress test，再调用 `grilling` skill。
本 skill 内部只用 ask_user 一次一问。
