# 自检清单（Cheklist）

每张图出图后必过这一关。漏了 caption box / 错字 / 风格漂移都比这严重。

## 一、逐张过（8 张每张都查）

| # | 检查项                                          | 通过？ |
| - | ----------------------------------------------- | ------ |
| 1 | 底部有 caption box？黑色边框 + 浅奶白底？       | ☐      |
| 2 | caption 中文渲染正确（无乱码 / 方块 / 错字）？  | ☐      |
| 3 | 4-6 格子？layout 不是千篇一律 2×2？             | ☐      |
| 4 | 关键页上了色（1-3 页）？色彩饱和度低、暖系？    | ☐      |
| 5 | 主角形象与 anchor 一致（圆头 / dot eyes）？     | ☐      |
| 6 | 没有画真名乐队 / 明星（用符号代替）？           | ☐      |
| 7 | 对白 / 拟声词文字渲染正确？                     | ☐      |
| 8 | 3:4 竖版比例正确？                              | ☐      |

**任何一项 ❌ → 修这一项（单页重跑或单字修），不扩散。**

## 二、整体过（8 张一起看）

| # | 检查项                                                  | 通过？ |
| - | ------------------------------------------------------- | ------ |
| 1  | 8 张连起来是 1 段完整的内心独白（caption 连读）？        | ☐     |
| 2  | 8 张独立打开都能看懂（caption box 起作用）？             | ☐     |
| 3  | 情绪曲线有起伏（P3 慢 / P6 高 / P8 释然）？              | ☐     |
| 4  | 主角形象在 8 张里统一（不会第 3 页变一个人）？           | ☐     |
| 5  | 上色页选在情绪峰值（不是低潮）？                        | ☐     |
| 6  | 整体风格和 anchor 一致（不会第 4 页忽然变写实）？        | ☐     |
| 7  | 没有任何页"出戏"（拟声词过重、画面跑题）？               | ☐     |
| 8  | publish-pack.md 写完？标题 / 正文 / 标签 / 备注都对得上？ | ☐     |

**任何一项 ❌ → 回炉对应步骤，不要凑合交付。**

## 三、交付前最后一关

- [ ] 8 张图都在 `manga/` 目录下，命名规范（`图1-标题-manga.png`）
- [ ] `brief.md` 落档（只落实际决策，不要硬填 6 问表）
- [ ] `publish-pack-manga.md` 落档
- [ ] 用 `<media>` 标签把 8 张图打包发给用户
- [ ] 提示用户发布前可以微调 caption 文案（如果他们想改）

## 四、常见错误模式速查

| 用户反馈                | 第一反应                                            |
| ----------------------- | --------------------------------------------------- |
| "看不懂在讲什么"         | caption box 漏了 / 文案太长 / 没有连起来            |
| "风格不统一"             | BASE_STYLE_BLOCK 没共用 / anchor 没锁               |
| "主角不像同一个人"       | 没给参考图 / prompt 里主角描述不一致                |
| "中文是乱码"             | 单字修或单页重跑（控制 caption 长度）               |
| "颜色太多看着累"         | 黑白为主、只 1-3 页上色                              |
| "看 3 页就审美疲劳"      | 格子 layout 没变化                                   |
| "乐队画得好奇怪"         | 立刻用符号代替（剪影 + 舞台）                       |
| "P3 那页没看懂"          | 几乎一定是 caption box 漏了，单独重跑               |

## 五、给用户的"自检"提示语

发布前可以问用户：

> "8 张图可以打开任一张独立看。底部 narrator 旁白框是 v2 加的关键设计——为了让单页也能讲清一个小节。如果你想改某页的旁白文案，告诉我，我帮你重跑该页。"
